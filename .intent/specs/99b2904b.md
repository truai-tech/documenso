# WhatsApp-Benachrichtigungen

## Intent

Nutzer sollen Benachrichtigungen zu Dokumenten-Ereignissen wahlweise per WhatsApp empfangen können, anstatt nur per E-Mail. So können Empfänger dort erreicht werden, wo sie am aktivsten sind, und wichtige Aktionen (z.B. eine ausstehende Unterschrift) schneller wahrnehmen.

## Summary

Jeder Nutzer kann in seinen Profileinstellungen eine Handynummer hinterlegen und wählen, ob er Benachrichtigungen per E-Mail, per WhatsApp oder über beide Kanäle erhalten möchte. Für alle Ereignisse, für die bisher E-Mails verschickt werden, wird dann zusätzlich oder alternativ eine WhatsApp-Nachricht an die hinterlegte Nummer gesendet.

## How It Works

### Profileinstellungen — Handynummer & Benachrichtigungskanal

- Im Bereich **Profileinstellungen** gibt es einen neuen Abschnitt „Benachrichtigungen".
- Der Nutzer kann dort eine **Handynummer** (inkl. Ländervorwahl) eintragen und speichern.
- Über eine **Auswahl** legt der Nutzer seinen bevorzugten Benachrichtigungskanal fest:
  - **Nur E-Mail** (Standard, bisheriges Verhalten)
  - **Nur WhatsApp**
  - **E-Mail und WhatsApp**
- Die Option „Nur WhatsApp" und „E-Mail und WhatsApp" sind nur wählbar, wenn eine gültige Handynummer hinterlegt ist. Ist keine Nummer eingetragen, bleibt die Auswahl auf „Nur E-Mail" beschränkt und es wird ein entsprechender Hinweis angezeigt.
- Wird eine Handynummer entfernt, fällt die Einstellung automatisch auf „Nur E-Mail" zurück.

### Handynummer-Verifizierung

- Nach dem Eintragen einer neuen Handynummer erhält der Nutzer eine **WhatsApp-Verifizierungsnachricht** mit einem einmaligen Code.
- Die Nummer gilt erst als verifiziert, nachdem der Code erfolgreich eingegeben wurde.
- Nur verifizierte Nummern können für WhatsApp-Benachrichtigungen genutzt werden.
- Die Verifizierung erfüllt gleichzeitig die von Meta geforderte **Opt-in-Pflicht** — der Nutzer stimmt damit aktiv dem Empfang von WhatsApp-Nachrichten zu.

### WhatsApp-Nachrichten

- Für jedes Ereignis, das bisher eine E-Mail auslöst, wird — entsprechend der Nutzereinstellung — zusätzlich oder alternativ eine WhatsApp-Nachricht verschickt. Dazu gehören u.a.:
  - Einladung zum Unterzeichnen eines Dokuments
  - Erinnerung an eine ausstehende Unterschrift
  - Dokument vollständig unterzeichnet (Abschluss-Benachrichtigung)
  - Dokument abgelehnt
  - Dokument abgebrochen / gelöscht
  - Empfänger aus Dokument entfernt
  - Sonstige dokumentenbezogene Systemereignisse (z.B. Ablauf, Selbst-Unterzeichnung)
- Die WhatsApp-Nachrichten enthalten die wesentlichen Informationen der jeweiligen E-Mail in kompakter Form: Dokumenttitel, relevante Aktion und einen direkten Link.
- Nachrichten werden über die **Meta Cloud API** (WhatsApp Business Platform) direkt versendet. Die Zugangsdaten werden serverseitig konfiguriert.
- Jeder Nachrichtentyp basiert auf einer **vorab von Meta genehmigten Nachrichtenvorlage** (sog. *Utility Message Template*). Ohne genehmigte Vorlage kann der jeweilige Nachrichtentyp nicht versendet werden.

### Nicht enthalten

- Keine WhatsApp-Benachrichtigungen für system- oder kontobezogene E-Mails (z.B. Passwort-Reset, E-Mail-Bestätigung, Admin-Benachrichtigungen) — diese bleiben ausschließlich per E-Mail.
- Kein Versand über andere Messaging-Kanäle (SMS, Telegram etc.).
- Keine individuelle Steuerung pro Ereignistyp — die Kanalwahl gilt für alle dokumentenbezogenen Benachrichtigungen.
- Keine WhatsApp-Nachrichten für Empfänger, die kein Nutzerkonto in Documenso haben (externe Unterzeichner ohne Konto erhalten weiterhin nur E-Mails).

## Included / Not Included

**Enthalten:**
- Neuer Abschnitt „Benachrichtigungen" in den Profileinstellungen
- Eingabe und Speicherung der Handynummer (mit Ländervorwahl)
- Handynummer-Verifizierung per WhatsApp-Code (gleichzeitig Meta Opt-in)
- Kanalauswahl: Nur E-Mail / Nur WhatsApp / Beides
- WhatsApp-Versand für alle dokumentenbezogenen Benachrichtigungen via Meta Cloud API
- Automatischer Fallback auf „Nur E-Mail" bei fehlender/entfernter Nummer

**Nicht enthalten:**
- WhatsApp für konto- oder sicherheitsbezogene E-Mails (Passwort-Reset etc.)
- Benachrichtigungen für externe Unterzeichner ohne Konto
- Granulare Steuerung pro Ereignistyp
- Weitere Messaging-Kanäle (SMS, Telegram etc.)
