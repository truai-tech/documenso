# WhatsApp Notifications

## Intent

Give document senders and their recipients the ability to receive Documenso notifications via WhatsApp instead of — or alongside — email, using the Meta Cloud API as the delivery channel.

---

## Summary

Today, every notification in Documenso is delivered by email. This feature introduces WhatsApp as a second notification channel. Document senders can opt in for themselves and choose WhatsApp when setting up each recipient. All document workflow notifications — signing invitations, reminders, completion, rejection, cancellation — are supported. Owner-side notifications (e.g. "a recipient has signed") follow the sender's own channel preference. Account and security emails (email confirmation, password reset, admin account setup) are not affected and always use email.

---

## How It Works

### Connecting a WhatsApp number (account holders)

- Under **Settings → Notifications**, a new **WhatsApp** section appears.
- The user enters their phone number in international format and clicks **Connect**.
- A WhatsApp verification message is sent; the user enters the code to confirm ownership.
- Once verified, the user sets their channel preference: **Email only**, **WhatsApp only**, or **Both**.
- This preference applies to all owner-side notifications: a recipient has signed, document fully completed, bulk send finished, organisation or team member changes, and team deletion.
- The phone number can be removed at any time, which reverts delivery to email.

### Adding a recipient phone number (document setup)

- When adding recipients to a document, each recipient row gains an optional **WhatsApp number** field alongside the existing name and email fields.
- If a phone number is provided, the sender selects the delivery channel for that recipient: **Email** or **WhatsApp**.
- If no phone number is provided, the recipient always receives email — no change to the current behaviour.
- The phone number set here is used only for that document and is not stored in the recipient's profile.

### Sending a notification via WhatsApp

- Notifications sent via WhatsApp use Meta-approved message templates.
- Each message includes: the sender's name or organisation name, the document title, a brief description of the required action (e.g. "You have been asked to sign"), and a link to the signing page or document view.
- WhatsApp messages do **not** include PDF attachments; recipients access the document through the link.
- If WhatsApp delivery fails (e.g. the number is invalid or not registered on WhatsApp), the system automatically falls back to email delivery and records the delivery attempt.

### Notifications covered

| Event | Recipient of notification | Channel |
|---|---|---|
| Signing invitation sent | Document recipient (signer, approver, viewer, CC) | Per-recipient choice |
| Signing reminder | Document recipient | Per-recipient choice |
| Document completed | Document recipient + document owner | Per-recipient / owner preference |
| Document cancelled | Document recipient | Per-recipient choice |
| Document rejected | Document owner | Owner preference |
| Recipient has signed | Document owner | Owner preference |
| Recipient link expired | Document owner | Owner preference |
| Document created from direct template | Document owner | Owner preference |
| Bulk send completed | Document owner | Owner preference |
| Organisation member joined | Organisation admins | Owner preference |
| Organisation member left | Organisation admins | Owner preference |
| Team deleted | Team members | Owner preference |

### System configuration

- An administrator configures the Meta Cloud API credentials in the environment settings: **WhatsApp Business Account ID**, **Phone Number ID**, and **API access token**.
- The WhatsApp channel is disabled system-wide until these credentials are provided.
- Organisations or teams do not manage their own Meta accounts; a single set of credentials covers the whole installation.

## Included / Not Included

**Included**
- WhatsApp delivery for all document workflow and account-holder notifications listed above
- Per-recipient phone number field and channel selector on the document setup screen
- WhatsApp number + channel preference in personal notification settings
- Automatic fallback to email if WhatsApp delivery fails
- Meta Cloud API integration, configurable via environment credentials

**Not Included**
- Account and security emails (email address confirmation, password reset, admin-created account) — these always use email regardless of preference
- Two-way WhatsApp messaging — recipients cannot reply through Documenso
- PDF attachment delivery via WhatsApp
- Per-organisation or per-team WhatsApp Business account configuration
- Custom WhatsApp message templates per organisation or per branding profile
- Storage of recipient phone numbers beyond the current document (no address book)
