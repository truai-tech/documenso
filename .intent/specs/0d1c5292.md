# WhatsApp Notifications

## Intent

Users currently receive all document event notifications exclusively by email. Some users prefer to be notified via WhatsApp — a channel they check more reliably. This feature lets each user opt into WhatsApp notifications by adding and verifying a phone number in their personal settings.

---

## Summary

Users can configure a WhatsApp phone number in their personal profile settings. Once the number is verified via a one-time code sent over WhatsApp, the user receives notifications for all document events through WhatsApp in addition to (or instead of, depending on their preferences) email.

Messages are sent via the WhatsApp Business API.

---

## How It Works

### Phone Number Setup (Settings > Profile)

A new **WhatsApp Notifications** section appears on the user's profile settings page. It contains:

- A phone number input field (international format)
- A toggle to enable or disable WhatsApp notifications
- The current verification status of the number

When a user enters a phone number and saves, the system immediately sends a one-time verification code via WhatsApp to that number. The user is prompted to enter the code to confirm ownership of the number. Once verified, the number is saved and WhatsApp notifications are activated.

If a user changes their phone number, the new number must be verified before it becomes active. The old number remains active until the new one is successfully verified.

The toggle allows a verified user to pause and resume WhatsApp notifications at any time without removing the number.

### Notifications

Once a user has a verified phone number and notifications enabled, they receive a WhatsApp message for every document event that would normally trigger an email notification:

| Event | Recipient |
|---|---|
| Signing request sent | The recipient |
| Recipient signed | The document owner |
| Document completed | All recipients + owner |
| Document still pending | The signer who just signed |
| Document deleted | All recipients |
| Recipient removed | The removed recipient |
| Recipient signing window expired | The document owner |
| Document created from direct template | The document owner |

WhatsApp messages contain the document name and a short description of the event. Where applicable, a direct link to the document is included.

Each event respects the same per-document email toggle settings — if an email notification type is disabled for a specific document, the corresponding WhatsApp message is also suppressed.

---

## Included / Not Included

**Included:**
- Phone number input and storage in user profile settings
- Verification flow via one-time code sent over WhatsApp Business API
- WhatsApp notifications for all existing document notification events
- Ability to enable/disable notifications without removing the number
- Re-verification required when phone number is changed

**Not included:**
- WhatsApp notifications for recipients who are not registered users (non-account signers receive only email)
- Per-event granular control over which WhatsApp notifications to send (all-or-nothing per user)
- Replacing email notifications entirely — WhatsApp notifications are additive
- Team- or organisation-level WhatsApp notification settings
